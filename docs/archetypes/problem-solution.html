Symptoms

You have seen all four

  1. 01It answers the question you asked ten turns ago.
  2. 02The format changes halfway through a list.
  3. 03It contradicts a constraint you set at the start.
  4. 04It re-explains something you already accepted.

The fix

Stop chatting. Start restating.

Drifting

Twenty turns of accumulated context.

  • Constraints buried at turn one
  • Model weighs stale turns equally
vs
Stable

One fresh message carrying the state.

  • Constraints restated at the top
  • Only the material that still matters
@rlnorthcutt
4 / 8
Method

Reset a drifting thread

  1. 1Ask it to summarise the state in ten lines.
  2. 2Correct that summary yourself — this is the real work.
  3. 3Open a fresh thread with the summary as the first message.
  4. 4Restate the format and the constraints above the task.

What resetting buys

Habits

Four habits that prevent it

  • Restate constraints every few turns
  • Start a new thread per task, not per day
  • Keep a written state summary outside the chat
  • Scroll up to find what you agreed
