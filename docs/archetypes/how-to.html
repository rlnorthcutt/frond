The premise

It never looks anything up. It predicts.

Every answer is the next token, then the next, chosen from a distribution over the whole vocabulary.

Four moves

Give it what it cannot infer

  1. 1Name the role and the reader — the model has no idea who is asking.
  2. 2Paste the material. Retrieval beats recall, always.
  3. 3Specify the output shape before the task, not after.
  4. 4Ask for the reasoning last, so it does not pad the answer.

Prompt hygiene

What separates a good prompt

  • One task per request
  • The source text pasted in, not referenced
  • An explicit format: table, JSON, three bullets
  • Please be accurate and do not hallucinate
  • Six questions stacked in one message
